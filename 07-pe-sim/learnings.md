# Learnings (3 bullets/day)

The point is not "what I did" — that's in your runbooks. The point is **what surprised you**.

A learning is something you didn't know yesterday, and now you do, and it changes how you'll act next time. It is NOT "I deployed an app today" or "I ran kubectl describe".

## Format

```
## Day N — YYYY-MM-DD
- Surprise: ...
- Insight: ...
- Question still open: ...
```

If you can't find three, you didn't poke hard enough today. Look at:

- Something you assumed that turned out wrong
- A command output you didn't fully understand
- A decision someone else (or the system) made that wasn't obvious why
